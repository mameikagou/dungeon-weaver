# Dungeon Weaver · 苔光地牢

浏览器地牢动作肉鸽：披风骑士、大剑三段连击、蓄力重斩、精力与翻滚、削韧处决；六间房、三类普通敌人、苔冠守望者 Boss，以及弹幕与突进两条祝福路线。原创程序化角色与场景。

**Bun 1.3.14 + Vite + TypeScript strict + Three.js + postprocessing + React + Tailwind CSS + Jotai。** 游戏微内核为独立的纯 TypeScript，浏览器与 Bun 共用战斗规则。

![Tabbit 中实际运行的披风骑士与大剑战斗](docs/images/greatsword.png)

## 运行

```sh
bun install --frozen-lockfile
bun run dev
```

打开 http://localhost:4173 ，使用桌面键鼠操作：

| 输入 | 动作 |
| --- | --- |
| WASD | 移动 |
| 鼠标左键 | 大剑三段连击；灵弹连射；靠近失衡敌人，松开后重新点击处决 |
| E 键（或鼠标右键） | 按住蓄力，松开重斩或发射贯穿弹；蓄力时移动减慢 |
| 空格 | 翻滚，消耗 24 精力，18 战斗帧无敌；可取消蓄力与挥击后摇末段 |
| Q | 在大剑和灵弹之间切换，需等待当前动作结束 |
| Esc | 暂停 |

初始装备大剑，三段伤害为 60 / 70 / 100，精力消耗为 14 / 16 / 22；满蓄力重斩伤害 150，消耗 28 精力。刀刃与刀光使用真实攻击角度，前摇与后摇不造成伤害，同一挥击对每个敌人只命中一次。精力上限 100，动作结束等待 0.75 秒后每秒恢复 30；不足时不能发动相应攻击或翻滚。

灵弹普通射击每发 18 点伤害、消耗 4 精力；蓄力至少 0.2 秒，1 秒蓄满，满蓄力每发 90 点伤害、消耗 18 精力，最多命中 8 个不同敌人。浏览器启用右键手势时使用 E 键。弹幕祝福用于灵弹，突进祝福可搭配两种武器。

普通弹削韧 5，满蓄力削韧 30；正面盾牌承受一半削韧。削空后敌人跪地 2 秒，露出金色弱点。进入 1.6 格内重新点击左键，执行 0.8 秒处决，全程无敌，中段造成 270 点伤害。Boss 同样可以处决。上述时间使用战斗帧，命中顿帧期间暂停计时。

```sh
bun test
bun run check:data
bun run sim --seed=42
bun run build
bun run preview
```

生产预览地址 http://localhost:4174 ，构建产物在 `dist/`。

## 战斗与构筑

- **冲锋兽**：橙色冲撞预告，方向锁定后横向躲避。
- **投弹怪**：紫色落点预告，1 秒后变红并造成范围伤害。
- **持盾卫兵**：正面抵挡，侧后方与挥击后的恢复阶段可受伤。
- **苔冠守望者**：轮流使用冲撞、三处落弹和九发扇形弹幕；半血后缩短恢复时间、加快弹幕。

路线共 46 个敌人，普通房间含 2～3 波遭遇。清房恢复 12 点生命并选择祝福，最后击败 Boss 通关。可选祝福不足三个时显示全部剩余选项。

| 路线 | 祝福 | 效果 |
| --- | --- | --- |
| 弹幕 | 分岔之光 | 增加两发散射，包括蓄力弹 |
| 弹幕 | 回声石 | 灵弹最多反弹两次 |
| 弹幕 | 折光 | 至少反弹一次，每次反弹伤害增加 50% |
| 突进 | 烬行 | 冲刺留下持续 1 秒的伤害轨迹 |
| 突进 | 破晓 | 翻滚后 2 秒内的下一次大剑或灵弹攻击伤害翻倍 |
| 突进 | 追猎 | 击杀 3 格内敌人恢复冲刺和 3 点生命 |

祝福可以混搭，每项最多一层。反弹、贯穿和持续伤害都有明确次数或间隔。

## 技术与验证

- 60Hz 固定步进、种子随机数、SoA 对象池、二维网格、墙体碰撞与距离场寻路。
- Three.js 实例化 Billboard，五类精灵轮廓、移动摆动、蓄力挤压、后坐力、命中闪白、击退、冲刺轨迹、消散与轻微震屏。
- ZzFX 缓存音效和 AudioContext 压缩器；Jotai `createStore()` 只接收变化的 HUD 状态。
- 开发入口 `window.__DEBUG__` 支持精确步进、状态读取、房间传送、祝福和敌人生成。
- Bun 与 Tabbit 使用真实规则验证；具体结果见[验证记录](docs/verification.md)。

单局 5～8 分钟是人工试玩目标，尚未验证。自动 Bot 可以更快通关。对象池容量为 2000 个敌人、5000 发投射物，满负载帧率和 GC 尚未测量。
