# 实际验证记录

2026-10-28，在 Bun 1.3.14、WSL 与 Windows Tabbit 环境中运行。

| 检查 | 结果 |
| --- | --- |
| Bun 规则测试 | 11 项通过；覆盖可重放战斗、分段步进、弹墙、冲刺、死亡、吸血、对象池、非法输入、HUD 与完整路线。 |
| 内容检查 | 3 个房间、5 个祝福，配置检查通过。 |
| TypeScript 与生产构建 | strict 类型检查和 Vite 构建通过。 |
| Bun 无头对局 | 种子 42，612 个基础 tick、552 个战斗 tick，击败 13 个敌人，生命 100，通关两间房。 |
| 浏览器与 Bun 一致性 | 同一训练场景推进 60 帧，Tabbit 取得的完整 JSON 与 Bun 结果相等。 |
| 精确步进 | 60 帧与两次 30 帧相等；暂停后等待浏览器动画帧，游戏状态保持不变。 |
| 真实 UI 和输入 | Tabbit 点击奖励进入余烬密室，键盘移动与冲刺、鼠标射击均通过。 |
| 生产浏览器预览 | 可以进入游戏，window.__DEBUG__ 不存在，页面及着色器错误列表为空。 |
| 视觉检查 | 已查看实际截图，角色、地面、弹幕、HUD 和祝福显示可见。 |

无头模拟只测试当前内容和 Bot 策略。当前结果不代表完整肉鸽难度，也不代表跨设备、所有输入序列均已验证。

对象池有 2000 敌人、5000 弹幕槽位；该容量下的帧时间、GC、峰值内存尚未测试。树木 Bayer 遮挡透视、残影、Boss 和随机路线尚未实现。音效代码已接入播放与压缩链路，实际听感仍需人工试玩评估。

构建器报告了 Jotai 的客户端指令提示和游戏主包体积提示，构建成功；当前是单页浏览器应用。需要按目标设备和网络条件继续测量加载时间。
